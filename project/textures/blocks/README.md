# Texturas base dos blocos

Texturas repetíveis 64×64 geradas para a direção de arte inicial do MVP:

| Arquivo | Material |
|---|---|
| `grass.png` | Grama |
| `dirt.png` | Terra |
| `stone.png` | Pedra |
| `sand.png` | Areia |
| `snow.png` | Neve |
| `wood.png` | Madeira |
| `leaves.png` | Folhas |
| `bedrock.png` | Rocha de fundo |

As imagens vieram de uma folha 4×2 de padrões pixelados, separada em tiles quadrados. São fontes de arte; o renderer de preview ainda não as consome. A aplicação nos octaedros depende de T03/T04: UV planar ortonormal com escala e fase globais, mantendo as pontas e ligações existentes.
